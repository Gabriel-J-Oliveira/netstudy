DHCP + CONFIGURAÇÃO DINÂMICA · ÁREA 01

Configuração antes da comunicação

O cliente começa sem IPv4 configurado. DHCP pode fornecer IP, máscara, gateway e DNS, cada um com uma função diferente para os próximos passos da comunicação.

DHCP fornece configuração; não substitui DNS, ARP, routing, TCP ou a aplicação.

ÁREA 02 · DORA

Quatro mensagens, no ritmo do aluno

Discover → Offer → Request → ACK. Neste cenário local, o cliente sem IP pode usar broadcast para encontrar o servidor DHCP.

ÁREA 03 · CONCESSÃO

Quatro informações, quatro funções

A concessão apresenta 192.168.10.50/24, gateway 192.168.10.1 e DNS 192.168.10.53. Inspecione cada campo no laboratório.

ÁREA 04 · DIAGNÓSTICO

APIPA é pista, não causa raiz

Compare a concessão válida com um endereço 169.254.x.x. Ele pode indicar que uma concessão DHCP não foi recebida; sozinho não aponta a causa. Alcance, VLAN, servidor ou conectividade precisam ser investigados.

Terminal simulado
Use ipconfig /all ou ipconfig /renew.

Saídas simuladas apenas para este cenário.

ÁREA 05 · SÍNTESE

Configuração em uso

Depois da concessão, o cliente consegue reconhecer sua rede local, usar o gateway para redes remotas e consultar DNS para nomes.

Configuração → rede local → gateway para redes remotas → DNS para nomes
