Fundamentos de redes

Encapsulamento e Desencapsulamento de Dados

Um pedido da aplicação precisa chegar ao serviço certo, atravessar redes e ser entregue em cada enlace. {% include "learning/partials/encapsulation_term.html" with key="encapsulation" term="Encapsulamento" definition="Cada camada recebe dados e acrescenta as informações necessárias para cumprir sua função na entrega." %} é o processo de preparar os dados para serem enviados pela rede. Cada camada acrescenta as informações necessárias para cumprir sua parte. No destino, as camadas interpretam essas informações e entregam a carga à camada seguinte.

PC-A · 1/5

PC-A prepara o frame para o primeiro enlace. O MAC de destino é o da interface de entrada do roteador.

Ao comparar os frames, observe o {% include "learning/partials/encapsulation_term.html" with key="ttl" term="TTL" definition="Limite de vida do pacote IPv4. Cada roteador que o encaminha reduz esse valor." %} e o {% include "learning/partials/encapsulation_term.html" with key="checksum" term="checksum" definition="Valor de verificação do cabeçalho IPv4. O roteador o atualiza quando altera o TTL." %} no IPv4. Na Ethernet, o {% include "learning/partials/encapsulation_term.html" with key="ethertype" term="EtherType" definition="Identifica o protocolo carregado pelo frame. O valor 0x0800 identifica IPv4." %} identifica a carga, enquanto o {% include "learning/partials/encapsulation_term.html" with key="fcs" term="FCS" definition="Campo de verificação colocado ao final do frame Ethernet para detectar erros na entrega pelo enlace." %} ajuda a detectar erros no frame.
