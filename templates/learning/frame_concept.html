01 · O QUE É UM FRAME ETHERNET?FRAME ETHERNET

O que é um Frame Ethernet?

OSI · CAMADA 2ENLACE DE DADOS
Um frame Ethernet é a estrutura utilizada pela Ethernet para transportar informações dentro de uma comunicação de Camada 2.
DADOS↓FRAME ETHERNET↓TRANSMISSÃO
PENSE ASSIM

Os dados são o conteúdo. O frame é a estrutura organizada utilizada para transportá-los naquela entrega Ethernet.

ONDE A COMPARAÇÃO TERMINA

Um frame não é literalmente uma caixa ou envelope. A comparação serve apenas para separar mentalmente o conteúdo da estrutura utilizada na transmissão.

OBSERVE
PC-ADados“Olá”
─────SWITCH─────
PC-B
DADOS“Olá”

Os dados ainda não estão em uma estrutura Ethernet.

Destination MACBB:BB:...
Source MACAA:AA:...
Dados“Olá”

Onde esse frame aparece?

HOST↓INTERFACE DE REDE↓FRAME ETHERNET↓SWITCH↓DESTINO LOCAL ou GATEWAY

O host transmite frames através de sua interface de rede. Switches recebem e encaminham frames dentro da rede Ethernet. Se o destino estiver fora da rede local, o primeiro frame é entregue ao gateway.

IPv4 · CAMADA 3IP destino final8.8.8.8
MAC · CAMADA 2Destination MAC do primeiro frameMAC do gateway

O destino IP pode permanecer remoto enquanto a primeira entrega Ethernet é feita ao gateway.

Switch e gateway aparecerão em conteúdos próprios.
