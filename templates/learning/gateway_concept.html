ÁREA 02 · DEFAULT GATEWAY

O gateway precisa ser localmente alcançável

O Default Gateway é o próximo salto utilizado pelo host quando o destino precisa ser alcançado através de outra rede e não existe uma rota mais específica aplicável.

Explique antes de revelar

Por que um pacote destinado a 192.168.20.50 pode sair de PC-A dentro de um frame cujo Destination MAC pertence ao gateway?

Resposta de referência

Porque PC-A identificou que 192.168.20.50 está fora de sua rede local. O destino IP continua sendo o host remoto, mas a primeira entrega Ethernet precisa chegar ao próximo salto local. Por isso o frame usa o MAC do gateway.
