02 · STP CLÁSSICO

STP mantém a redundância sem deixar todos os caminhos encaminharem

O Spanning Tree Protocol: troca informações entre switches para organizar caminhos redundantes em uma árvore lógica. troca BPDUs, elege uma Root Bridge e calcula quais portas encaminham. Uma porta Blocking continua conectada e recebe BPDUs, mas não encaminha dados de usuário. Nesta aula usamos somente o STP clássico.

O que observar: prioridade e Bridge ID → custos até a raiz → papel de cada porta → árvore sem ciclo ativo.

Preparar e prever

Altere prioridades ou custos e recalcule. O resultado é determinístico: menor Bridge ID vence; os custos e identificadores de porta desempatarão os caminhos.
