Portas + Cliente/Servidor

IP identifica o host. Protocolo e porta de destino ajudam a entregar os dados ao endpoint correto. Neste cenário, o cliente inicia a solicitação e o servidor oferece o serviço; nenhum deles escolhe a rota.

Um Um lado identificado de uma comunicação de transporte: protocolo, endereço IP e porta. combina protocolo, IP e porta para identificar onde os dados devem chegar. A Porta de origem escolhida para esta comunicação do cliente. A resposta pode usar essa porta como destino. identifica o lado cliente desta comunicação.

Um pedido e sua resposta

Servidor · 192.168.20.30 ofereceTCP 443 · WebTCP 22 · SSHUDP 53 · DNS
SOLICITAÇÃO · CLIENTE → SERVIDORTCP · 192.168.10.20:53012 → 192.168.20.30:443
RESPOSTA · SERVIDOR → CLIENTETCP · 192.168.20.30:443 → 192.168.10.20:53012

TCP 53 e UDP 53 são endpoints distintos: o protocolo também faz parte da identificação. O número da porta, sozinho, não é o programa nem garante o mesmo serviço em toda máquina.
