PORTAS + CLIENTE/SERVIDOR · ÁREA 01

IP leva ao host. E a aplicação?

Vários serviços podem compartilhar o mesmo IP de um servidor. O endereço 192.168.20.30 leva ao host; protocolo e porta de destino ajudam a selecionar o endpoint de transporte de um serviço dentro dele.

IP responde “qual host?”. Protocolo + porta responde “qual endpoint de aplicação nesse host?”.

ÁREA 02 · SERVIÇOS

Um IP, três serviços

No mesmo servidor, selecione um serviço e acompanhe a entrega. Uma porta não é o programa inteiro: ela identifica um endpoint de transporte usado por um serviço ou processo.

Protocolo também importa: TCP 53 e UDP 53 são endpoints de transporte distintos.

ÁREA 03 · CLIENTE

A porta temporária do cliente

No cenário web, o cliente envia de 192.168.10.20:53012 para 192.168.20.30:443 usando TCP. A porta 53012 é temporária neste cliente e ajuda a resposta a retornar ao endpoint correto.

O destino é 443 porque esse é o serviço web do servidor neste cenário. A origem não precisa usar a mesma porta.

ÁREA 04 · RESPOSTA

O retorno inverte os endpoints

Na resposta deste modelo cliente/servidor, o serviço web envia de 192.168.20.30:443 para 192.168.10.20:53012, ainda por TCP.

A porta do serviço permanece do lado do servidor. A porta temporária identifica o endpoint do cliente que iniciou esta comunicação.

ÁREA 05 · SÍNTESE

Dois clientes, o mesmo serviço

192.168.10.20:53012 e 192.168.10.21:53013 podem acessar o mesmo 192.168.20.30:443. A combinação abaixo distingue os fluxos; não é uma fórmula para decorar.

Protocolo + IP origem + porta origem + IP destino + porta destino

Terminal simulado · netstat
Use netstat -ano ou netstat -ano | findstr :443.

Saídas simuladas apenas para este cenário.

Explique antes de revelar

O IP identifica o host servidor. Como ele oferece serviços diferentes, protocolo e porta de destino indicam o endpoint de transporte usado pelo serviço que deve receber os dados.

Explique antes de revelar

53012 é a porta temporária de origem do cliente neste cenário. Ao responder, o servidor inverte origem e destino, enviando de TCP 443 para 192.168.10.20:53012.
