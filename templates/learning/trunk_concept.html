Trunk + 802.1Q

Veja como duas VLANs compartilham um Conexão entre interfaces de rede que transporta dados. Aqui, liga as interfaces Gi0/8 de SW1 e SW2; o termo também pode descrever uma conexão lógica, não apenas um cabo. e acompanhe um frame em seu percurso.

CONCEITO

Um enlace, vários contextos VLAN

Trunk é um enlace configurado para transportar tráfego de várias VLANs entre equipamentos de rede.

802.1Q é o padrão usado neste cenário para identificar a qual VLAN cada frame pertence enquanto atravessa esse enlace. Essa identificação é o Número que identifica a VLAN indicada pela tag 802.1Q. No percurso, ele acompanha o frame da VLAN 10 ou 20..

Os hosts entram e saem por portas Porta que, neste cenário, associa o tráfego do host à VLAN configurada. Outras configurações Access podem ter comportamentos adicionais..

EXEMPLO

A e C pertencem à VLAN 10; B e D pertencem à VLAN 20. Os Dispositivos finais, como PCs ou servidores, que enviam e recebem dados. Neste exemplo, A, B, C e D são hosts. estão distribuídos entre dois equipamentos. O Trunk transporta as duas VLANs pelo mesmo enlace, e a identificação 802.1Q permite manter cada frame em seu contexto.

Na entrada, a porta Access associa o frame sem tag ao contexto VLAN correspondente.

Entrada Access: no início, o host envia um Frame sem identificação 802.1Q explícita. A Native VLAN é um caso opcional relacionado, descrito no detalhe abaixo.; a porta Access associa o tráfego à VLAN.

Saída Access: o lado receptor usa o VLAN ID para entregar o frame ao contexto VLAN correspondente; o host não precisa processar a tag.

Allowed VLANs: uma VLAN pode ser bloqueada sem derrubar o enlace. Hosts de VLANs diferentes precisam de roteamento de Camada 3 para comunicar.

Native VLAN

O 802.1Q também define uma Native VLAN. Em configurações tradicionais, os frames dessa VLAN podem atravessar o trunk sem uma tag explícita.

AUTOEXPLICAÇÃO

Por que o frame precisa ser identificado ao atravessar um Trunk?

Resposta de referência

O enlace compartilhado pode transportar frames de várias VLANs. A identificação 802.1Q permite que o lado receptor mantenha cada frame no contexto VLAN correspondente. Na saída Access, o host recebe o frame sem precisar processar a tag.
